# Mish Ana! game art

Mish Ana! (مش أنا!) is game #1 of JAMAA. Its "shared bang" wordmark and its speech-bubble icon (DESIGN.md §1.3) were the app's brand until the JAMAA rename; they are now **game art**, shown on the game's poster and setup screen (JAMAA-PLATFORM §1.3, §3.9; DESIGN-JAMAA §1.4). The platform brand lives in [`assets/brand/`](../../brand/README.md).

All text is converted to outlines from **Cairo Black** (SIL OFL 1.1; the TTFs ship in `tv-app/app/src/main/res/font/`). Everything here is generated by `scripts/gen_logo.py`: do not edit the files by hand.

| File | What |
|---|---|
| `wordmark-bilingual.svg` | `MISH ANA ! مش أنا`, the two halves sharing one bang (stem magenta `#FF3D8B`, dot amber `#FFC23D`, text cream `#FFF7EC`) |
| `wordmark-latin.svg`, `wordmark-ar.svg` | each half with the bang |
| `mark.svg` | 160 × 160 bubble + bang on the night tile |
| `icon.svg` | the game icon on its palette-B tile (was the launcher / Play icon, design-v3 D2) |
| `icon-bubble.svg` | the icon's bubble + bang without the tile |

Generated TV code: `tv-app/app/src/main/java/app/jamaa/tv/games/mishana/MishanaLogoPaths.kt`, drawn by `MishanaLogo` in the same folder.

```sh
pip install fonttools uharfbuzz
python3 assets/games/mishana/scripts/gen_logo.py
```
