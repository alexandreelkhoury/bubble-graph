# Product review: IMPECCABLE lens (production quality)

Target: phone controller (`web-client/src/screens`, `styles.css`), browser TV (`web-client/src/tv-mock/tv.css`), native TV (`tv-app/.../ui`).
Method: `impeccable` skill (audit + product register). I computed every contrast ratio with the WCAG 2.x relative-luminance formula from the token hex values, compositing alpha and opacity over the real background. The script is `scratchpad/cr.py`. I read the screenshots in `shots/`. I read the code and did not edit it.

## 1. Verdict

The base tokens are good: every text token passes AA on every surface. The lowest pair is muted `#A193B8` on overlay `#362752` at **4.70:1**. TV focus looks the same on web and native, and the RTL engineering is above average.

The failures come from things layered on top of the tokens:
- **Alpha "dimming".** The TV-02 dimmed Start is the first element that gets focus. It measures **1.35:1** on native and **2.59:1** focused.
- **A missing font weight.** The web never loads Cairo 700, so every "700" token renders as 900. The browser TV, which is the live product today, therefore has a flatter type hierarchy than the native app.
- **Native/web parity drift.** The results title colour, the toast style and the settings-category marker differ between the two TVs.
- **Banned decoration.** Gradient text on the win title, and side-stripe borders.

Audit health: A11y 3 · Perf 3 (lightly assessed: font budget only) · Responsive 3 · Theming 3 · Anti-patterns 3 = **15/20, Good**.

## 3. Keep list (excellent, do not regress)

1. **One focus style on both TVs.** The web uses `--tv-focus-ring` (2 px bg gap, 3 px cream ring, primary glow, scale 1.04/1.06; `tokens.css:110`, `tv.css:51-54`) and native uses `MishFocus` (`MishSurface.kt:28-53`), which is the same. The focus is unambiguous from 3 m (`tv-03-settings-game-row-focused.png`, `tv-11-results-stage1.png`).
2. **Base contrast.** All text tokens are ≥ 4.70:1 on every surface (secondary 7.67–11.66, accent 8.31+). Ink-on-player-colour faces get an 8% white lift so coral reaches **4.75:1** (`styles.css:423-424`). Glyph colours (ink or cream) come from one shared table (`shared/src/constants.ts:61-72`) used by web and native.
3. **RTL engineering.** Logical properties throughout. Timer bars, done-fill and the word-card slide directions mirror. Codes and numbers are bidi-isolated (`.num`, `.tvcode`). Arabic line-height overrides are set at token level, and the Arabic wordmark is swapped. The Arabic e2e shots are clean apart from #5.
4. **Reduced-motion architecture.** Durations shrink at token level, there are per-element fade replacements on both web files, and native gates every `rememberInfiniteTransition` on `ANIMATOR_DURATION_SCALE` (`PlayerTile.kt:112`, `Brand.kt:182`, `TimerRing.kt:89`). #12 and #13 only fill gaps in this.
5. **The 10-foot type floor.** Nothing on the TV is below 20 dp (caption, label, body). Arabic gets ×1.08 on display sizes. The phone body is 17 px at weight 600. The scale is legible across the room.
